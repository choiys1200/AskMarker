# Qubble 다운로드

**현재 버전: v0.12.0** · [GitHub 최신 릴리스](https://github.com/choiys1200/Qubble/releases/latest)

| 파일 | 용도 |
|---|---|
| [qubble-v0.12.0.zip](qubble-v0.12.0.zip) | Chrome/Edge에서 압축 해제 후 설치 |
| [qubble-v0.12.0-source.zip](qubble-v0.12.0-source.zip) | 전체 소스·테스트·Notion 인증 백엔드 |
| [설치 ZIP SHA-256](qubble-v0.12.0.sha256) / [소스 ZIP SHA-256](qubble-v0.12.0-source.sha256) | 파일 무결성 확인 |

읽기 모드에서 원문 선택 → 코멘트 추가 → 질문 선택 → 프롬프트 만들기/모아서 입력/복사를 사용할 수 있습니다. 설정·기록 관리·도움말은 기본으로 접혀 있습니다. ChatGPT·Gemini·Grok 등 선택 가능한 AI 페이지를 지원하며, 서비스별 DOM/입력창 구조에 따라 호환성이 달라질 수 있습니다.

기존 사용자는 먼저 기록을 백업하고 ZIP의 `qubble` 폴더 **안의 파일**을 Chrome/Edge에 등록한 **같은 폴더**에 덮어쓴 뒤 확장과 AI 탭을 새로고침하세요. [자세한 사용·업데이트 안내](../README.ko.md)

이 폴더의 이전 버전 ZIP은 개발 이력과 호환 테스트를 위한 보관본입니다. 현재 사용에는 위 v0.12.0을 사용하세요. 2026-11-07 배포 문서 정리는 런타임을 변경하지 않습니다. [변경 내역](../docs/CHANGES-0.12.0.md) · [검증 범위](../docs/VALIDATION.md)
