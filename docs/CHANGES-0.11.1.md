# 0.11.1 — 차분한 코멘트 작성 말풍선

- 작성·수정 말풍선의 원색 90% 채우기를 제거하고 해당 Q 색조를 은은하게 섞은 배경으로 바꿨습니다. 어두운 화면에서는 짙은 색조, 밝은 화면에서는 연한 색조를 사용합니다.
- 외곽은 선택한 색의 3px 테두리로 강조합니다. 말풍선 꼬리도 본체와 같은 배경·테두리를 사용합니다.
- 입력란은 별도의 부드러운 배경과 1px 경계로 구분하고, 원문·안내 문구는 조금 낮은 밝기의 글자로 정리했습니다. 본문·입력·안내 글자에는 opacity를 적용하지 않습니다.
- 개별 Q의 색상과 전역 UI 테마를 구분하며, 새 작성과 기존 코멘트 수정에 같은 스타일을 적용합니다.
- v0.11.0의 UI 테마·Q1/Q2 표기와 기존 기록·백업 호환성을 유지합니다. 원문 연결·저장·프롬프트 삽입 로직은 변경하지 않았습니다.

기존 설치 폴더에 새 파일을 덮어쓰고 확장을 새로고침한 다음 AI 탭을 새로고침하세요. 설치 경로를 바꾸거나 확장을 제거하지 마세요. 작성 중인 초안은 업데이트 전에 저장하세요.

검증 환경과 실행 결과는 [VALIDATION](VALIDATION.md)을 참고하세요.
