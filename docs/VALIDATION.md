# Qubble 0.12.0 검증

2026-11-03–04 Asia/Seoul. v0.12.0 개발 기준은 `ce50e44`이며 검증한 런타임은 [배포 커밋 185a830](https://github.com/choiys1200/Qubble/commit/185a83025912494793f1a35569841665effe1ebc)에 포함되어 있습니다. 총 **28개 검증 모음 통과**.

| 환경 | 확인 결과 |
|---|---|
| Node 계약·모의 저장소/API | 기존 기록·선택·프롬프트 원문 유지, 모듈 경계, 인증 오류/취소·응답 유실·중복 방지·삭제 후 업로드 차단 통과 |
| 실제 unpacked MV3 + 격리 Chromium + 합성 HTML | 28개 모음의 브라우저 항목 통과. 실제 사용자 계정/AI 사이트를 사용하지 않음 |
| 설치된 Microsoft Edge 156.0.4314.58 + 별도 임시 프로필 + 합성 HTML | `qubble-ui` 통과: 기본 접힘, 키보드·포커스, 빠른 열기/닫기, 초안, 편집/복사/삽입, 한영·160%·다크·새로고침 |
| 기존 v0.11.3 설치 ZIP → v0.12.0 파일 덮어쓰기 → 확장 reload → 브라우저 재시작 | 같은 설치 ID, 모든 로컬 키/값, 질문/체크/설정, 아카이브 이력·receipt, JSON 형식 보존. Qubble 제목/도구 모음 확인 |
| 기존 v0.7.3 설치 ZIP → 새 버전 | 폐기된 아이콘 설정 한 키 외 나머지 전체 저장값 보존, 고정 아이콘 유지 |

설치 ZIP을 실제로 풀어 Chromium과 Microsoft Edge에서 `qubble-ui`를 다시 통과했습니다. 압축 내부 런타임은 검증한 소스 번들과 바이트 단위로 일치하며, 전체 소스 ZIP을 푼 경로에서도 재현 빌드 검사를 통과했습니다.

## 새 UI에서 직접 확인한 내용

- 읽기 모드·프롬프트 만들기·모아서 입력·복사·선택 개수가 기본 화면에 표시됩니다. 설정·기록 관리·도움말·각 Q 팔레트는 기본으로 접힙니다.
- Space로 접힘 영역을 열고 Escape로 닫으며, 포커스가 버튼으로 돌아옵니다. 닫힌 영역은 클릭/키보드 포커스를 받지 않습니다.
- 애니메이션을 켠 채 12회 빠르게 접기/펼치기를 반복했습니다. 초안 텍스트와 원문 소유권, 읽기 모드와 저장 선택 상태가 유지됩니다.
- 10회 이상 실제 마우스 드래그·추가·빈 초안 취소, 저장 후 연속 추가, 같은/다른 원문 선택을 회귀 검증했습니다.
- 말풍선/오른쪽 수정 동기화, 질문별 색상과 전체 테마 분리, 복사 후 선택 유지, 확인된 삽입 후 선택 해제, 기존 입력 보존·중복 방지를 확인했습니다.
- 8색·라이트/다크 작성 박스 대비, 160% 한영 표시, 390px 너비, 낮은 창의 실제 휠 스크롤, 동작 줄이기, 새로고침을 확인했습니다.
- 기존 v0.2 기록, v3/v4 JSON 백업·병합, 코드/메일 박스, 여러 문단·표·목록, DOM 재생성·대화 전환을 검증했습니다.

ChatGPT/Gemini/Grok/Claude 어댑터 검증은 **해당 구조를 재현한 합성 HTML**입니다. 실제 AI 서비스의 최신 화면, 사용자의 Chrome 프로필, 실제 OAuth 승인·Notion/Drive 운영 API 저장은 이번에 확인하지 않았습니다. 실제 서비스 화면의 별도 확인은 남아 있습니다.

처음 전체 실행에서 접힌 설정/새 스크롤 영역에 맞지 않던 기존 테스트 탐색을 수정한 뒤 해당 모음과 후속 모음을 재실행했습니다. 제품 기능 확인을 생략하지 않고 실제 접힘 버튼을 열어 접근합니다. [개별 결과와 runtime SHA-256](validation/v0.12.0/summary.json), [변경 내역](CHANGES-0.12.0.md)을 참고하세요. 스크린샷은 로컬 QA 폴더에만 두며 저장소/배포에 포함하지 않습니다.

```powershell
node scripts/build.cjs --check
node scripts/test.cjs
# Edge: QA_BROWSER를 설치된 msedge.exe로 지정
node scripts/test.cjs qubble-ui
```
