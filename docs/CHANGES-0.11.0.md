# 0.11.0 — 선택 색상 테마와 Q 표기

- 기존 오른쪽 색상 선택으로 전체 UI 테마를 변경합니다. 주요 버튼·hover·포커스·읽기 모드 스위치·체크·메뉴 배경/구분선·안내 메시지·내보내기 화면에 공통 색상 토큰을 적용합니다.
- 선택한 테마는 기존 마지막 색상 설정에 보관하고 새로고침/다른 탭의 내보내기 화면에 복원합니다. 다른 항목을 클릭하는 것만으로 전체 테마를 다시 바꾸지 않습니다. 개별 Q의 원문 형광펜과 저장 색상은 유지합니다.
- 작성·수정 중인 코멘트 박스는 해당 항목 색상의 3px 테두리와 `rgba(r,g,b,0.9)` 배경으로 표시합니다. 전체 요소에 opacity를 적용하지 않습니다. 입력란은 투명하게 두어 박스 배경이 이중으로 겹치지 않습니다.
- 밝은/어두운 화면에서 검정·흰색 글자를 선택하여 8색 모두 최소 4.5:1 본문 대비를 확보합니다. 버튼 글자·포커스도 선택 색상을 따릅니다.
- 표시 제목 `Mark 1`, `Mark 2` → `Q1`, `Q2`. 한국어·영어 UI, 체크박스 설명, 새 프롬프트와 마지막 지시문, 새 내보내기 문서 제목에 적용합니다.
- ‘코멘트 추가’, ‘내 코멘트’, ‘모아서 입력’은 유지합니다. 제품 이름 AskMarker와 기존 고정 도구 모음 아이콘은 유지합니다.
- 저장 키·`question`·`markIds`·JSON v3/v4 구조는 변경하지 않습니다. 원문·사용자 코멘트·과거 생성 프롬프트와 이미 승인된 스냅샷은 다시 쓰지 않습니다. 구 Mark 프롬프트의 중복 검사도 유지합니다.

`domain/theme.js`는 순수 색상/대비 계산, `ui/theme.js`는 확장용 CSS 토큰 적용만 담당합니다. 테마 기능은 원문 위치·기록 저장·입력 전송 로직에 의존하지 않습니다.

검증 환경과 미검증 범위는 [VALIDATION](VALIDATION.md)에 기록합니다. 실제 사용자 Chrome/실제 AI 서비스와 OAuth는 이 작업에서 실행하지 않습니다.
