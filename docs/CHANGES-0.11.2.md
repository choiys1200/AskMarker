# 0.11.2 — 투명한 코멘트 추가 버튼

- 드래그 후 표시되는 ‘코멘트 추가’ 버튼의 배경을 완전히 투명하게 변경했습니다. 그림자와 backdrop blur도 없애 뒤의 본문을 덮거나 흐리지 않습니다.
- 마우스를 올리거나 키보드로 포커스를 옮겨도 배경은 투명합니다. 버튼 글자·테두리·포커스 표시는 유지합니다.
- 버튼의 세로 여백을 절반으로 줄이고 선택한 문장 아래 간격을 6px에서 2px로 줄여 다음 줄을 덜 가립니다. 본문을 밀어내는 공간은 추가하지 않습니다.
- 버튼을 눌러 여는 코멘트 작성 말풍선의 차분한 배경과 3px 테두리는 유지합니다. 저장·선택·취소·원문 연결·프롬프트 기능은 유지합니다.

작성 중인 초안을 먼저 저장하고, 기존 설치 폴더에 새 파일을 덮어쓴 뒤 확장과 AI 탭을 새로고침하세요. 기록을 유지하려면 확장을 제거하거나 설치 경로를 바꾸지 마세요.
