# 0.10.1 — 입력 후 안내 간소화

- 입력 완료 문구를 ‘입력창에 추가했습니다.’ / ‘Added to input.’으로 단축.
- 성공 안내를 4.5초에서 1.5초로 단축. 일반 안내는 2.2초, 오류 안내는 4.5초.
- 안내를 입력창 위 최소 16px 여백에 배치하고 화면 경계 안에 유지. 기본 하단 여백은 140px.
- 안내는 클릭을 가로채지 않음.
