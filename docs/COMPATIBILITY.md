# Qubble 저장 호환성

제품명과 현재 공개 안내는 Qubble을 사용합니다. 아래 식별자는 기존 기록·설치·외부 문서를 계속 찾기 위한 데이터 계약입니다.

| 식별자 | 유지 이유 |
|---|---|
| `qb:note:*`, `qb:prompt-choice:*`, `qb:appearance:*` | 원문·코멘트·포함 선택·표시 설정을 같은 저장소에서 복원 |
| `question-basket-backup`, `question`, `markIds` | 이전 JSON 백업과 아카이브 요청 묶음 읽기 |
| `am:archive:*`, `askmarker-archive` | 기존 아카이브 기록·승인 취소·서비스 워커 통신 |
| `question-basket-extension`, `__questionBasketV1`, `--askmark-*` | 확장 인스턴스·스타일·원문 인덱스의 기존 계약 |
| Notion의 `AskMarker <snapshot ID>` 표식 | 이미 저장한 원격 페이지와 응답 유실 후 재시도를 같은 문서로 연결 |

Notion 표식의 문자열만 바꾸면 이전에 저장된 페이지를 찾지 못해 중복 생성 또는 결과 확인 실패가 생길 수 있습니다. 제품 소개 문구와 구분해 내부 호환성 표식으로 유지합니다. 기존 외부 문서나 사용자 원문에 들어 있는 단어를 일괄 수정하지 않습니다.

기록을 보존하려면 현재 ZIP의 내용물을 **같은 등록 폴더**에 덮어쓰고 확장과 AI 탭을 새로고침하세요. 폴더 이름을 바꾸거나 기존 확장을 삭제·재등록하면 설치 ID가 달라질 수 있습니다.

과거 ZIP·SHA-256·태그와 검증 결과는 당시 상태를 재현하기 위해 보관합니다. [개발 이력](history/README.md)은 현재 사용 설명과 구분합니다.
