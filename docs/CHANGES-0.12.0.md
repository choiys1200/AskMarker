# Qubble 0.12.0

기준: `main`의 `ce50e44` (v0.11.3), 2026-11-03 확인.

## 화면

- 제품 표시명, manifest 이름·설명·도구 모음 제목, 한영 라벨, 최신 안내 문서를 Qubble로 변경했습니다.
- 메인 화면은 읽기 모드, 프롬프트 만들기, 모아서 입력·복사, 질문 목록에 집중합니다. 설정·기록 관리·도움말은 기본으로 접힙니다.
- 작은 색 점을 누르면 해당 Q의 팔레트만 열립니다. 체크박스와 미선택 상태는 별도이며, 원문·코멘트·선택 상태를 보존합니다.
- 색조를 줄인 표면, 카드 간격, 조용한 보조 버튼, 읽기 쉬운 선택 상태로 정리했습니다. 본문 아래 말풍선과 3px 작성 테두리, 불투명 코멘트 추가 버튼은 유지합니다.
- 패널·미리보기·입력 안내·접힘 영역을 160ms 전환으로 통일합니다. 닫힌 컨트롤은 클릭/탭으로 접근되지 않으며 빠르게 다시 열어도 남은 닫기 타이머가 화면을 숨기지 않습니다. 동작 줄이기 환경에서는 애니메이션을 생략합니다.

## 기능 및 호환성

원문 선택, 저장/취소, 초안, 질문 수정/삭제·색상, 포함 선택, 미리보기 편집, 복사, 기존 입력 뒤에 추가, 삽입 성공 후 선택 해제, 언어·글꼴·크기·포인터, 백업·가져오기, 아카이브/OAuth 기능은 유지합니다.

저장 키/필드·JSON 형식·아카이브 journal/RPC·Notion 중복 방지 표식은 변경하지 않습니다. 제품명 변경 때문에 새 확장으로 재등록하지 말고 ZIP의 `qubble` 폴더 내용물을 **기존 등록 폴더**에 덮어쓴 뒤 새로고침하세요. 새 권한이나 외부 전송은 없습니다.

## 코드 검토 순서

1. `src/ui/shell.html`, `panel.css`, `base.css`: 정보 구조와 시각 변화.
2. `src/ui/motion.js`, `panel.js`, `cards.js`: 전환/포커스/접힘 경계.
3. `src/app.js`, `i18n/messages.js`, `domain/theme.js`: 기존 동작 연결과 문구/표시만 변경.
4. manifest/README/패키징: v0.12.0 배포와 이름 변경.
5. `tests/qubble-ui-test.cjs`, 업데이트/기존 회귀 테스트: 실제 확장 로드 환경의 보존 확인.

검증 범위와 아직 미확인인 실제 AI/OAuth 범위는 [VALIDATION.md](VALIDATION.md)를 참고하세요. `content.js`, `background.js`, `archive.js`는 빌드 생성물입니다.
