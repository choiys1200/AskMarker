# AskMarker · 질문 바구니 0.7.5

**Read. Mark. Ask again.**

AI 답변을 읽으며 원문에 질문을 달고, 모아서 다시 묻는 Chrome 확장입니다. **ChatGPT·Gemini·Grok 등 여러 AI 웹페이지에서 사용**하는 도구이며, ChatGPT를 읽는 흐름에 맞춰 전용 연동을 더했습니다. 다른 서비스에서는 일반 웹페이지 모드로 표시·질문·복사를 사용합니다. 별도 AI API·서버·회원가입이 필요하지 않습니다.

[설치 ZIP](releases/askmarker-v0.7.5.zip) · [전체 소스 ZIP](releases/askmarker-v0.7.5-source.zip) · [모듈 구조](docs/ARCHITECTURE.md) · [검증 보고서](docs/VALIDATION.md)

## 기본 아이콘

0.7.5에서는 펼친 패널의 AskMarker 이름 옆에도 같은 MarkChat 물음표 아이콘을 표시합니다.

**MarkChat 하나를 AskMarker의 고정 아이콘으로 사용합니다.** 말풍선과 형광펜 표시가 도구 모음과 확장 관리 화면에 나타나며, 별도 선택이나 설정은 필요 없습니다. 0.7.3에서 키운 크기를 유지합니다.

0.7.4는 나머지 4개 디자인·아이콘 선택 화면·패널 버튼을 제거했습니다. 업데이트 시 이전 아이콘 선택 설정만 정리하고 질문·체크 상태·읽기 설정은 보존합니다. 원본 SVG와 6개 크기의 투명 PNG를 제공합니다.

## 0.7.1 이름 변경

확장 이름·화면·문서·설치 파일을 **AskMarker**로 통일했습니다. 저장 키와 백업 형식은 그대로입니다. 기존 설치 폴더에 파일을 덮어써 확장 ID와 기록을 유지하세요. GitHub 저장소는 [choiys1200/AskMarker](https://github.com/choiys1200/AskMarker)입니다.

## 0.7.0에서 추가한 기능

- 원문 인식·복원, 프롬프트 생성·입력, 체크 상태 저장, UI·화면 설정을 모듈로 분리했습니다. 글꼴·포인터 설정은 질문이나 원문 저장 정보를 수정하지 않습니다.
- 중립적인 배경, 얇은 테두리와 간격으로 UI를 정리했습니다. `AskMarker 펼치기` / `AskMarker 접기`와 읽기 모드 ON/OFF는 펼쳤을 때와 접었을 때 같은 스타일을 사용합니다. 패널을 열어 둔 상태에서도 읽기 모드를 바꿀 수 있습니다.
- 시스템 기본·고딕·명조·고정폭 글꼴을 선택합니다. AskMarker UI와 읽기 모드의 답변 문단에 적용합니다. 코드 글꼴은 유지하고, 시스템 기본은 사이트 본문 글꼴을 덮어쓰지 않습니다. 설치되지 않은 글꼴은 로컬 기본 계열로 대체됩니다.
- 포인터 **진하기 0–100%**로 투명도를 조정합니다. 0%는 보이지 않으며 100%는 가장 진합니다. 선택한 색으로 채워지고 바깥으로 갈수록 희미해지는 형태와 클릭을 방해하지 않는 동작을 유지합니다.
- ChatGPT의 편집 가능한 메일·메시지 예시 박스에서도 드래그 후 질문을 추가할 수 있습니다. 코드·작성 박스의 질문은 박스 바로 아래에 배치합니다. 사이트 편집기 안에 질문 DOM을 넣지 않습니다.
- **프롬프트가 입력창에 정상 추가된 뒤 해당 묶음의 체크를 자동 해제합니다.** 기록·형광펜·말풍선은 남습니다. 다음에 새로 저장한 질문은 기본 체크됩니다. 이전 질문을 다시 넣으려면 직접 체크합니다.
- 입력 실패·취소·단순 복사에서는 체크를 유지합니다. 복사만으로 외부 입력창에 실제 붙여넣었는지 확인할 수 없기 때문입니다. 추가 도중 저장한 새 질문도 해제하지 않습니다.

## 사용

1. ChatGPT에서는 자동으로 나타납니다. **Gemini·Grok 등에서는 먼저 Chrome 도구 모음의 AskMarker 아이콘을 누릅니다.** 읽기 모드를 켜고 답변을 드래그합니다. 작은 **질문 추가** 버튼만 나타나므로 드래그하며 계속 읽을 수 있습니다.
2. **질문 추가**를 누르고 원문 아래 말풍선에 질문을 저장합니다. 빈 창을 취소해도 다시 선택할 수 있습니다.
3. 오른쪽에서 색상·포인터 진하기·글꼴을 선택합니다. 질문별 색상 버튼은 12px 크기를 유지합니다.
4. 질문 제목의 체크 상태를 확인한 뒤 ChatGPT 입력창을 클릭하고 **모아서 입력**을 누릅니다. 다른 AI에서는 **바로 복사** 또는 미리보기에서 복사하고 직접 붙여넣습니다. 전송은 항상 직접 합니다.
5. ChatGPT 입력창에 정상 추가 후 체크가 해제됩니다. 단순 복사에서는 체크를 유지하므로, 다른 AI에 붙여넣은 뒤 새 묶음을 시작하려면 **선택 해제**를 누릅니다. **전체 선택**도 가능합니다.

오른쪽 **입력창에 바로 추가**, **바로 복사**, **프롬프트 미리보기·수정**을 사용할 수 있습니다. 입력창 클릭 확인 기능은 읽기 모드와 별도로 ON/OFF를 저장합니다. 이미 입력된 원문·질문 쌍은 중복 추가하지 않습니다.

읽기 모드 OFF는 본문 표시만 숨깁니다. 질문은 로컬에 보관하며 새로고침 후에도 남습니다. ChatGPT는 대화 식별 정보로, 다른 사이트는 전체 페이지 URL로 구분합니다. 다른 사이트가 여러 대화에 같은 URL을 쓰면 같은 목록을 공유합니다. 현재 탭의 초안은 모드 전환 동안 유지되지만 탭 종료·새로고침까지 저장되지는 않습니다. 원문이 변경되어 위치를 확인할 수 없으면 기록을 목록에 보관하고 비슷한 다른 문장에 붙이지 않습니다.

## 설치와 기존 기록 유지 업데이트

처음 설치할 때는 설치 ZIP을 풀고 Chrome 확장 프로그램의 개발자 모드에서 `manifest.json`이 있는 `askmarker` 폴더를 로드합니다. 설치 ZIP은 이미 빌드되어 있어 Node.js가 필요하지 않습니다.

기존 사용자는 다음 순서로 업데이트합니다.

1. 기존 확장의 **전체 기록 백업**으로 기록을 보관합니다.
2. 새 ZIP의 **모든 파일과 하위 폴더**(`assets/` 포함)를 Chrome에 등록된 **기존 설치 폴더에 덮어씁니다**.
3. 확장 프로그램 관리 화면에서 기존 확장을 새로고침하고 사용 중인 탭도 새로고침합니다. ChatGPT 외 사이트에서는 확장 아이콘을 다시 누릅니다.
4. 패널의 **v0.7.5**를 확인합니다.

기존 확장을 삭제하거나 다른 경로에 등록하면 확장 ID와 저장소가 분리될 수 있습니다. 질문 저장 키 `qb:note:`, 체크 키 `qb:prompt-choice:`, 백업 형식과 기존 권한은 유지합니다. 이전 원문 인덱스는 이전 규칙으로 읽고 새 작성 박스 기록에만 확장된 인덱스를 적용합니다.

## 사이트별 기능과 검증

| 기능 | ChatGPT | Gemini·Grok 등 다른 AI 웹페이지 |
| --- | --- | --- |
| 시작 | 자동 표시 | 확장 아이콘 클릭 |
| 원문 선택·형광펜·질문·목록·미리보기·복사 | 전용 답변 인식 | 선택 가능한 일반 DOM 텍스트 대상 |
| 입력창에 추가 / 입력창 클릭 확인 | 지원 | 복사 후 직접 붙여넣기 |
| 원문 복원 | 메시지 식별 정보와 정확한 텍스트 위치 | 저장한 페이지 텍스트가 일치해야 복원. 주변 내용이 바뀌어도 표시가 숨겨질 수 있으나 기록은 보존 |

다른 AI의 모든 화면 구조를 보장하는 것은 아닙니다. iframe·닫힌 Shadow DOM·이미지처럼 그려진 텍스트·편집 가능한 답변 위젯에는 일반 모드가 적용되지 않을 수 있습니다. 답변 본문 글꼴 변경과 편집 가능한 작성 박스 처리는 ChatGPT 전용이며, AskMarker UI 글꼴 변경은 공통입니다.

0.7.5는 격리 Chromium에 실제 MV3 확장을 로드해 화면 설정·프롬프트 입력 검증 모음을 실행했습니다. 밝은 화면과 어두운 화면의 패널 아이콘도 확인했습니다. 이전 버전 결과는 별도 보관합니다.

검증용 HTML은 실제 AI 서비스 응답이 아닙니다. **새 0.7.5를 설치한 실제 ChatGPT·Gemini·Grok 대화와 회사 PC는 미검증입니다.** [검증 보고서](docs/VALIDATION.md)에서 구분합니다.

## 개발

소스는 `src/`를 수정합니다. **`content.js`는 생성 파일이므로 직접 수정하지 않습니다.** 자세한 책임·의존 경계와 글자 크기 기능 추가 예시는 [모듈 구조](docs/ARCHITECTURE.md)에 있습니다.

```sh
npm install
npm run build
npm run check:build
npm test
python scripts/package.py
```

이전 배포 ZIP을 사용하는 업데이트 검증은 `QA_PYTHON`에 Python 경로를 설정합니다. `QA_BROWSER`는 확장을 지원하는 Chromium 실행 경로로 설정합니다. `QA_OUTPUT`으로 검증 결과 폴더를 지정할 수 있습니다. 빌드는 Node 표준 라이브러리만 사용하며 설치본에는 외부 로더·프레임워크·네트워크 의존성이 없습니다. `npm run check:build`는 소스와 배포 파일이 정확히 일치하는지 검사합니다.

질문은 `chrome.storage.local`에만 저장합니다. 글꼴도 외부에서 다운로드하지 않습니다. 백업 파일에는 원문과 질문이 포함됩니다.
