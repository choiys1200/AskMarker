# Qubble

**질문 때문에 읽던 흐름을 끊지 마세요.**

AI 답변을 읽다가 궁금한 문장에 질문을 남기고 계속 읽으세요. Qubble은 원문과 질문을 연결해 기록하고, 필요한 질문만 골라 하나의 후속 프롬프트로 만듭니다.

**Read. Mark. Ask again.**

## 왜 Qubble인가요?

ChatGPT의 긴 답변을 읽다가 이해되지 않거나 근거를 확인하고 싶은 문장을 만날 때가 있습니다. 그 자리에서 바로 질문하면 읽던 흐름이 끊기고, 끝까지 읽은 뒤 질문하려면 어떤 문장이 궁금했는지 다시 찾아야 합니다.

Qubble은 **읽는 과정의 질문 기록**과 **다음 프롬프트 작성**을 분리합니다.

## 사용 방법

1. **읽기:** 읽기 모드를 켜고 AI 답변의 문장을 선택합니다.
2. **질문 남기기:** **코멘트 추가**를 눌러 원문 아래 말풍선에 질문을 적고 계속 읽습니다. 선택만 했을 때 입력창이 열리지는 않습니다.
3. **모으기:** 질문과 원문이 연결된 채 오른쪽 목록에 남습니다. 다음에 물어볼 질문만 체크합니다.
4. **다시 묻기:** 선택한 질문을 미리보기·수정하거나 입력창에 모아서 추가·복사합니다. 전송은 직접 합니다.

**차별점:** 드래그한 문장을 바로 입력창에 누적하는 대신, **읽는 동안 질문을 말풍선에 남겨 보존하고 나중에 선별해 묻는 Workflow**에 초점을 맞췄습니다.

### 사용 데모

실제 AI 웹페이지에서 동작하는 확장을 녹화한 데모를 준비할 예정입니다. 그 전까지는 아래 설치본과 사용법으로 기능을 확인할 수 있습니다. 시뮬레이션 영상은 실제 설치 동작 검증과 구분해 표시합니다.

## 설치

1. [Qubble v0.12.0 설치 ZIP](releases/qubble-v0.12.0.zip)을 내려받아 압축을 풉니다.
2. Chrome의 `chrome://extensions` 또는 Edge의 `edge://extensions`에서 개발자 모드를 켭니다.
3. **압축 해제된 확장 로드**에서 `manifest.json`이 들어 있는 `qubble` 폴더를 선택하고 ChatGPT 탭을 새로고침합니다.
4. ChatGPT에서는 자동 시작하며, Gemini·Grok 등 다른 페이지는 확장 아이콘을 클릭해 시작합니다.

Chrome·Edge 모두 Chromium 기반이지만 실제 호환성은 각 AI 사이트의 DOM/입력창 구조에 따라 달라집니다. 자동 테스트는 격리 브라우저와 합성 HTML을 사용했으며 **실제 모든 AI 사이트·계정의 동작을 보증하지 않습니다.**

## 핵심 기능에 집중한 화면

메인 화면에는 읽기 모드, 질문 목록, 선택 개수, 프롬프트 생성·모아서 입력·복사를 배치했습니다. **설정**, **기록 관리**, **사용 도움말**은 기본으로 접혀 있으며 질문별 색상도 필요할 때만 표시합니다. 짧은 전환 효과와 동작 줄이기 설정을 지원합니다.

읽기 모드를 끄면 원문 표시만 숨기고 질문 기록은 유지합니다. 초안은 탭 안에서 패널·모드 전환 동안 유지하지만 탭을 닫으면 사라질 수 있습니다.

## 개인정보와 기록

질문·설정은 `chrome.storage.local`에 저장합니다. 기본 기능에는 AI API 키나 별도 계정·서버가 필요하지 않습니다. 질문을 자동 전송하지 않으며 **기록 관리**에서 JSON으로 전체·대화별 백업 및 가져오기를 할 수 있습니다.

선택적 Notion/Google Drive 아카이브 내보내기는 기본 OFF이며 별도 OAuth 설정과 사용자의 명시적 승인 절차가 필요합니다. 배포본에는 실제 인증 설정이 들어 있지 않습니다. 과거 대화 전체를 자동 수집하거나 기기 사이에 자동 동기화하지 않습니다. [아카이브 설정](docs/ARCHIVE-SETUP.md) · [개인정보·권한](docs/PRIVACY.md)

## 기존 질문을 유지하며 업데이트

기록을 백업한 뒤 새 ZIP의 `qubble` 폴더 **안의 파일**을 기존 브라우저에 등록한 **같은 확장 폴더**에 덮어쓰세요. 그 폴더 이름이 AskMarker여도 바꾸지 마세요. 다른 경로에 새로 등록하면 확장 ID와 저장소가 달라질 수 있습니다. 확장과 AI 탭을 새로고침한 뒤 Help의 버전을 확인합니다.

기존 질문·선택 키 및 v3/v4 JSON 백업과의 호환성은 유지합니다.

## 개발·검증

`src/` 수정 후 `node scripts/build.cjs`로 빌드하며, `npm test`는 확장 지원 Chromium을 사용합니다. `python scripts/package.py`로 설치 ZIP과 소스 ZIP을 생성합니다.
