# AskMarker · 질문 바구니 0.8.1

**Read. Mark. Ask again.**

AI 답변을 읽으며 표시한 원문에 질문을 달고, 모아서 다시 묻는 Chrome 확장입니다. ChatGPT·Gemini·Grok과 선택 가능한 텍스트가 있는 다른 AI 웹페이지에서 사용합니다. 별도 API·서버·회원가입이 필요하지 않습니다.

[설치 ZIP](releases/askmarker-v0.8.1.zip) · [전체 소스 ZIP](releases/askmarker-v0.8.1-source.zip) · [검증 보고서](docs/VALIDATION.md) · [모듈 구조](docs/ARCHITECTURE.md)

## 0.8.1 메뉴 숨기기

작은 메뉴의 **숨기기**를 누르면 현재 탭의 메뉴가 사라집니다. **도구 모음의 AskMarker 아이콘**을 누르면 작은 메뉴가 다시 나타납니다. 질문·초안·읽기 모드와 메뉴 위치는 유지하며, 질문 본문의 표시는 읽기 모드 설정을 따릅니다. 새로고침하면 기본 작은 메뉴로 시작합니다.

## 0.8.0 변경

- Gemini·Grok 입력창 인식을 추가했습니다. 다른 AI에서도 일반 textarea·ProseMirror·편집 가능한 textbox/combobox를 인식합니다.
- 입력창에 마우스를 잠깐 올리거나 클릭하면 **모아서 입력** 안내가 뜹니다. 확인하면 기존 입력 뒤에 추가하고 해당 묶음의 체크를 해제합니다. 실제 전송은 직접 합니다.
- 오른쪽 안내 ON/OFF를 유지하며 OFF에서도 **입력창에 바로 추가**를 사용할 수 있습니다. 여러 입력창이 있으면 먼저 원하는 창을 가리키거나 클릭합니다.
- 글씨 크기는 **시스템·브라우저 기본**이 기본값입니다. **직접 입력**을 선택하면 80–160%를 숫자나 슬라이더로 조절합니다. 메뉴와 질문 말풍선에 적용합니다.
- 기본 보라는 MarkChat 아이콘과 같은 **#6554e8**입니다. 기존 보라 항목을 교체하며 8색을 유지합니다. 새 질문은 이 색으로 시작하며 이후에는 마지막으로 고른 색을 기억합니다.

## 사용

1. ChatGPT에서는 자동으로 나타납니다. **Gemini·Grok 등 다른 사이트에서는 먼저 도구 모음의 AskMarker 아이콘을 누릅니다.**
2. 읽기 모드를 켜고 원문을 드래그합니다. 작은 **질문 추가** 버튼을 눌러 원문 아래 말풍선에 질문을 저장합니다. 계속 읽으며 반복할 수 있습니다.
3. 오른쪽 목록의 **[ ] 질문 N**에서 다음 프롬프트에 포함할 질문을 고릅니다. 저장한 새 질문은 기본 체크되며, 이전에 입력한 질문은 직접 다시 선택해야 포함됩니다.
4. AI 입력창에 마우스를 올리거나 클릭한 뒤 **모아서 입력**을 누릅니다. 기존 글은 유지하며 이미 들어 있는 원문·질문 쌍은 건너뜁니다.
5. 필요하면 오른쪽 **프롬프트 미리보기·수정**이나 **바로 복사**를 사용합니다. 지원하지 않는 편집기는 복사해서 직접 붙여넣습니다. 복사만 하면 체크를 유지합니다.

선택한 원문·말풍선·오른쪽 목록은 같은 질문을 보여주며 수정·색상·삭제가 함께 반영됩니다. 읽기 모드 OFF는 본문 표시만 숨깁니다. 기록은 로컬에 남고 다시 ON 하면 정확한 원문을 찾을 수 있는 표시를 복원합니다. 작성 중 초안은 모드 전환 동안 유지되지만 새로고침·탭 종료까지 저장되지는 않습니다.

접힌 오른쪽 메뉴 위쪽 손잡이를 드래그해 위아래로 옮깁니다. 위치는 저장되며 창 크기가 바뀌면 화면 안으로 조정됩니다. 방향키와 Home/End도 지원합니다. 폰트·글씨 크기·포인터 진하기는 오른쪽에서 설정합니다. MarkChat 물음표 아이콘 하나를 고정 사용합니다.

## 사이트별 범위

| 기능 | ChatGPT | Gemini·Grok | 다른 일반 AI 웹페이지 |
| --- | --- | --- | --- |
| 시작 | 자동 | 확장 아이콘 클릭 | 확장 아이콘 클릭 |
| 형광펜·질문·목록·미리보기·복사 | 전용 답변 인식 | 일반 본문 모드 | 일반 본문 모드 |
| 입력 안내·확인 후 추가 | 전용 입력창 | 관찰한 편집기 속성에 대응 | 일반 textarea·편집 가능한 textbox/combobox·ProseMirror |
| 질문 분리 | 대화 ID | 전체 페이지 URL | 전체 페이지 URL |

모든 AI 사이트의 모든 화면을 보장하지는 않습니다. iframe·닫힌 Shadow DOM·이미지로 그린 글·특수 편집기는 인식되지 않을 수 있습니다. 입력 결과를 확인하지 못하면 질문 체크를 유지하고 복사를 안내합니다. 다른 사이트가 여러 대화에 같은 URL을 쓰면 같은 질문 목록을 공유합니다. 원문이 바뀌면 비슷한 문장에 추측 연결하지 않고 목록에 기록을 보관합니다.

## 설치와 기록을 유지하는 업데이트

처음에는 설치 ZIP을 풀고 Chrome 확장 관리 화면의 개발자 모드에서 `manifest.json`이 있는 `askmarker` 폴더를 로드합니다. Node.js는 필요하지 않습니다.

기존 사용자는 **전체 기록 백업** 후 ZIP의 모든 파일·하위 폴더를 **등록된 기존 설치 폴더에 덮어씁니다.** 확장과 페이지를 새로고침하고 **v0.8.1**을 확인합니다. **Gemini·Grok 등에서는 확장 아이콘을 다시 누릅니다.** 기존 확장을 삭제하거나 다른 경로에 새로 등록하면 ID/저장소가 분리될 수 있습니다.

질문·체크 저장 키와 백업 형식은 유지합니다. 기존 직접 조절 값과 선택한 색도 유지합니다. 이전 '현재 크기' 설정은 시스템 기본으로 읽습니다. 색이 없던 구버전 질문의 노랑 표시는 보존합니다.

## 검증

0.8.1은 메뉴 숨김/복원과 관련된 5개 검증 모음을 통과했습니다. 실제 도구 모음 콜백을 테스트 코드로 호출해 재주입을 검사했으며 실제 도구 모음 클릭과는 구분합니다. 0.8.0의 전체 19개 결과는 별도 기록입니다. 실제 Chrome에서 Gemini·Grok 입력창 속성을 읽기 전용으로 관찰했고, 그 구조의 합성 HTML에서 입력 기능을 검사했습니다. **실제 서비스에서 새 버전의 입력 동작과 회사 PC는 미검증입니다.** [환경별 검증 보고서](docs/VALIDATION.md)

## 개발·개인정보

`src/`를 수정하고 `npm run build`로 `content.js`를 생성합니다. `npm test`는 Playwright와 확장 지원 Chromium이 필요합니다. `QA_BROWSER`, 필요하면 `QA_PYTHON`과 `QA_OUTPUT`을 설정합니다. `python scripts/package.py`로 설치·소스 ZIP을 만듭니다.

질문과 설정은 `chrome.storage.local`에 저장됩니다. 외부 API 호출·폰트 다운로드·자동 전송은 없습니다. 백업에는 인용 원문과 질문이 들어갑니다. OpenAI·Google·xAI와 제휴한 제품이 아닙니다.
